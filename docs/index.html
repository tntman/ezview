A fast, minimal media viewer for Windows. Images, video, image sequences and 3D scenes in one clean, dark window.

View on GitHub Build it

C# / .NET 9 · Avalonia · libmpv · ImageMagick · Assimp · own Alembic, USD and Quake 3 readers

Opens almost anything

Double-click a file and it's just there. The rest of its folder becomes the queue.

Images

jpg, png, webp, heic, avif, jxl, tiff, psd, exr, hdr, dds, tga, svg, camera RAW and 200+ more via ImageMagick.

Video & audio

Everything mpv plays: mkv, mp4, HEVC, AV1, ProRes, webm, gif, mp3, flac… with hardware decoding.

Image sequences

shot.1001.exr, plate_0001.dpx… play as a clip with real frame numbers.

3D models

obj, fbx, gltf/glb, stl, ply, dae, blend, 3ds, Quake md2/md3/mdl, Doom 3 md5 and more.

3D animation

Alembic, USD (usda/usdc/usdz with references, payloads, variants, instancing) and FBX skeletons.

Quake 3 maps

BSP levels straight from .pk3, with textures and lightmaps.

Features

Out of the way when you're looking, right there when you need it.

Window & playback

  • Chromeless dark window with a frosted top bar and player bar that fade out while you watch
  • Timeline with real frame numbers, frame stepping with ← →
  • Loop off / file / queue, play-queue toggle, volume and speed control
  • Double-click for fullscreen

Image inspection

  • View RGB, single R / G / B, alpha or luminance
  • Exposure from −6 to +6 EV and gamma 0.2–3
  • Pixel readout: exact RGBA, hex and float under the pointer
  • Adjustments carry over to the next image for comparison

3D viewport

  • Houdini-style navigation: LMB tumble, MMB pan, RMB dolly through the scene
  • Click to select objects, F flies the camera to them
  • Wireframe, grid, textures, skeleton and hide-geometry toggles
  • Outliner with hierarchy, visibility and solo

Panels

  • Queue panel for the current folder or sequence
  • Info panel with full metadata and EXIF
  • Side panels resize by dragging their inner edge
  • Everything also reachable from the right-click menu

Windows integration

  • ezview --register adds it to "Open with" for every supported type
  • --unregister removes it cleanly
  • Built-in self test for sequence grouping and 3D formats

Build

Needs the .NET 9 SDK. Video also needs libmpv (~120 MB, not in the repo): grab an mpv-dev-x86_64-*.7z from shinchiro/mpv-winbuild-cmake and put libmpv-2.dll in native/ next to ezview.csproj.

# clone and build
git clone https://github.com/tntman/ezview
cd ezview
dotnet build

# release build
dotnet publish -c Release -o publish
# command line
ezview <file>
ezview --register
ezview --unregister
ezview --selftest
